## 1. [measure]

```python
import keras
from keras import layers

keras.utils.set_random_seed(0)

model = keras.Sequential([
    keras.Input((8, 8, 1)),
    layers.Conv2D(8, 3, padding="valid"),
    layers.MaxPooling2D(2),
    layers.Conv2D(16, 3, padding="valid"),
    layers.GlobalMaxPooling2D(),
])
for layer in model.layers:
    print(f"{layer.__class__.__name__:20s} {tuple(layer.output.shape)[1:]} weights {layer.count_params()}")
print("convolution weights:", sum(l.count_params() for l in model.layers))
```

```text
Conv2D               (6, 6, 8) weights 80
MaxPooling2D         (3, 3, 8) weights 0
Conv2D               (1, 1, 16) weights 1168
GlobalMaxPooling2D   (16,) weights 0
convolution weights: 1248
```

The first convolution has 3 × 3 × 1 × 8 + 8 = 80 weights. The second has 3 × 3 × 8 × 16 + 16 = 1,168. The pooling layers have none.

## 2. [break]

```python
import keras
import numpy as np
from keras import layers
from examples.digits import load

x_train, x_test, y_train, y_test = load(images=True)
keras.utils.set_random_seed(0)
model = keras.Sequential([
    keras.Input((8, 8, 1)),
    layers.Conv2D(16, 3, padding="same", activation="relu"),
    layers.Conv2D(32, 3, padding="same", activation="relu"),
    layers.GlobalMaxPooling2D(),
    layers.Dense(10),
])
model.compile("adam", keras.losses.SparseCategoricalCrossentropy(from_logits=True), metrics=["accuracy"])
model.fit(x_train, y_train, epochs=40, batch_size=32, verbose=0)

def shift_right(x, d):
    out = np.zeros_like(x)
    out[:, :, d:, :] = x[:, :, :-d, :] if d else x
    return out

for d in (1, 2, 3):
    cut = float((x_test[:, :, -d:, :].max(axis=(1, 2, 3)) > 0).mean())
    accuracy = model.evaluate(shift_right(x_test, d), y_test, verbose=0)[1]
    print(f"shift {d}: images that lose ink {cut:.3f}, accuracy {accuracy:.3f}")
```

```text
shift 1: images that lose ink 0.140, accuracy 0.991
shift 2: images that lose ink 0.911, accuracy 0.973
shift 3: images that lose ink 0.996, accuracy 0.713
```

A shift moves the columns at the right edge out of the frame. The last column of each row of the table counts the images that lose ink in this way. The network cannot recover what is gone. The invariance of the chapter holds while the digit stays inside the 8 × 8 frame. The frame is small, so the limit is reached quickly.

## 3. [judge]

**Position:** the statement is too strong. Convolution is translation equivariant, and invariance needs a pooling step and has limits.

**What a good answer weighs.** The chapter measures three things. A convolution followed by flatten fell to 0.638 under a one-pixel shift. A convolution followed by global max pooling stayed at 0.991. The invariance broke when the digit left the frame. A grid also does not mean that position is irrelevant: a form, a chessboard and a spectrogram have meaning in the position. For those, a flatten or a position code is correct.

**Strongest objection.** Large images have much more room, and the pooling makes the shift limit unimportant in practice. This is true for natural images, and it is the reason CNNs work there. The chapter's data are small and the border effect is large.

**What would overturn it.** A measurement on the colleague's own images with several shift sizes, as in the solution to exercise 2.
