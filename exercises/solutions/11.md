## 1. [measure]

```python
import keras
from keras import layers

keras.utils.set_random_seed(0)

d, u = 16, 32
by_hand = {"Embedding": 10 * 16, "GRU": 3 * (d * u + u * u + 2 * u), "Dense": 32 * 1 + 1}
print("by hand:", by_hand, "total", sum(by_hand.values()))

model = keras.Sequential([keras.Input((16,), dtype="int32"), layers.Embedding(10, 16),
                          layers.GRU(32), layers.Dense(1)])
print("count_params:", model.count_params())
```

```text
by hand: {'Embedding': 160, 'GRU': 4800, 'Dense': 33} total 4993
count_params: 4993
```

The factor 3 is the three gates of a GRU: the reset gate, the update gate and the candidate. The `2 × u` is two bias vectors for each gate, which the Keras default `reset_after=True` uses. The two numbers agree.

## 2. [break]

```python
import keras
import numpy as np
from keras import layers

rng = np.random.default_rng(0)

def make(n, length=16, vocabulary=10):
    x = rng.integers(3, vocabulary, size=(n, length))
    positions = np.array([rng.permutation(length)[:2] for _ in range(n)])
    x[np.arange(n), positions[:, 0]] = 1
    x[np.arange(n), positions[:, 1]] = 2
    return x.astype("int32"), (positions[:, 0] < positions[:, 1]).astype("int32"), positions

x_train, y_train, _ = make(6000)
x_test, y_test, positions = make(2000)

keras.utils.set_random_seed(0)
model = keras.Sequential([keras.Input((16,), dtype="int32"), layers.Embedding(10, 16),
                          layers.Conv1D(32, 3, activation="relu"), layers.GlobalMaxPooling1D(),
                          layers.Dense(32, activation="relu"), layers.Dense(1)])
model.compile("adam", keras.losses.BinaryCrossentropy(from_logits=True))
model.fit(x_train, y_train, epochs=15, batch_size=64, verbose=0)
correct = (model.predict(x_test, verbose=0)[:, 0] > 0).astype("int32") == y_test

far = np.abs(positions[:, 0] - positions[:, 1]) >= 3
interior = ((positions >= 4) & (positions <= 11)).all(axis=1)
edge = ((positions <= 1) | (positions >= 14)).any(axis=1)
for name, chosen in (("interior pairs", far & interior), ("edge pairs", far & edge)):
    print(f"{name:15s} {int(chosen.sum()):4d} pairs, accuracy {correct[chosen].mean():.3f}")
```

```text
interior pairs   250 pairs, accuracy 0.504
edge pairs       742 pairs, accuracy 1.000
```

The candidate is confirmed. Pairs with both tokens inside the sequence score 0.504, which is chance. Pairs with a token at the edge score 1.000. The `conv` model has no position input. It reads the edge from the way a token at the border appears in fewer windows. This is a leak of position that works only at the border, and it explains why the accuracy of the chapter's table did not fall steadily with the distance.

## 3. [judge]

**Position:** ship the bag-of-words model, and keep the recurrent model as a challenger.

**What a good answer weighs.** The gap is 0.01. On a test set of a few hundred transcripts, one transcript is a few thousandths, and a gap of 0.01 is within the noise of a single split. The chapter's task is built so that order is the only signal, and there the bag scores at chance. For topic classification, the words carry most of the signal, and the chapter gives no reason to expect that order matters. The bag is 60 times cheaper to train and simpler to run. The first step is to find out whether order carries signal in this data, for example with the bag-versus-order test of the chapter on the team's own labels.

**Strongest objection.** The recurrent model may help on the rare topics that are decided by phrases such as "not interested". A mean accuracy hides this. Look at the per-topic scores.

**What would overturn it.** A per-topic table in which the recurrent model wins on the topics that matter by more than the spread over seeds, or a business rule that errors on one topic cost much more than errors on the others.
