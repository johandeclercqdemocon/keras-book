## 1. [measure]

```python
import keras
from keras import layers, ops
from examples.digits import load

class BalancedAccuracy(keras.metrics.Metric):
    def __init__(self, num_classes=10, name="balanced_accuracy", **kwargs):
        super().__init__(name=name, **kwargs)
        self.num_classes = num_classes
        self.hits = self.add_variable(shape=(num_classes,), initializer="zeros", name="hits")
        self.counts = self.add_variable(shape=(num_classes,), initializer="zeros", name="counts")

    def update_state(self, y_true, y_pred, sample_weight=None):
        y_true = ops.cast(ops.reshape(y_true, (-1,)), "int32")
        predicted = ops.cast(ops.argmax(y_pred, axis=-1), "int32")
        hit = ops.cast(ops.equal(predicted, y_true), "float32")
        onehot = ops.one_hot(y_true, self.num_classes)
        self.hits.assign(self.hits + ops.sum(onehot * ops.expand_dims(hit, -1), axis=0))
        self.counts.assign(self.counts + ops.sum(onehot, axis=0))

    def result(self):
        return ops.mean(self.hits / ops.maximum(self.counts, 1.0))

    def reset_state(self):
        self.hits.assign(ops.zeros_like(self.hits))
        self.counts.assign(ops.zeros_like(self.counts))

x_train, x_test, y_train, y_test = load()
keras.utils.set_random_seed(0)
model = keras.Sequential([keras.Input((64,)), layers.Dense(64, activation="relu"), layers.Dense(10)])
model.compile("adam", keras.losses.SparseCategoricalCrossentropy(from_logits=True),
              metrics=[BalancedAccuracy()])
model.fit(x_train, y_train, epochs=3, batch_size=32, verbose=0)
for batch_size in (1, 450):
    result = model.evaluate(x_test, y_test, batch_size=batch_size, verbose=0, return_dict=True)
    print(f"batch size {batch_size:3d}: balanced accuracy {result['balanced_accuracy']:.5f}")
```

```text
batch size   1: balanced accuracy 0.89342
batch size 450: balanced accuracy 0.89342
```

The metric keeps the number of hits and the number of images of each class. These counts do not depend on how the images are grouped into batches. A metric that averaged a per-batch value would change with the batch size, and a batch of one image would give a meaningless per-class mean.

## 2. [break]

```python
import keras
from keras import layers, ops
from sklearn.metrics import balanced_accuracy_score
from examples.digits import load

class Broken(keras.metrics.Metric):
    def __init__(self, num_classes=10, name="balanced_accuracy", **kwargs):
        super().__init__(name=name, **kwargs)
        self.num_classes = num_classes
        self.hits = self.add_variable(shape=(num_classes,), initializer="zeros", name="hits")
        self.counts = self.add_variable(shape=(num_classes,), initializer="zeros", name="counts")

    def update_state(self, y_true, y_pred, sample_weight=None):
        y_true = ops.cast(ops.reshape(y_true, (-1,)), "int32")
        predicted = ops.cast(ops.argmax(y_pred, axis=-1), "int32")
        hit = ops.cast(ops.equal(predicted, y_true), "float32")
        onehot = ops.one_hot(y_true, self.num_classes)
        self.hits.assign(self.hits + ops.sum(onehot * ops.expand_dims(hit, -1), axis=0))
        self.counts.assign(self.counts + ops.sum(onehot, axis=0))

    def result(self):
        return ops.mean(self.hits / ops.maximum(self.counts, 1.0))

    def reset_state(self):
        pass

x_train, x_test, y_train, y_test = load()
keras.utils.set_random_seed(0)
model = keras.Sequential([keras.Input((64,)), layers.Dense(64, activation="relu"), layers.Dense(10)])
model.compile("adam", keras.losses.SparseCategoricalCrossentropy(from_logits=True), metrics=[Broken()])
history = model.fit(x_train, y_train, epochs=3, batch_size=32,
                    validation_data=(x_test, y_test), verbose=0).history
correct = balanced_accuracy_score(y_test, model.predict(x_test, verbose=0).argmax(axis=1))
print("broken, validation, per epoch:", [round(v, 4) for v in history["val_balanced_accuracy"]])
print("correct value after epoch 3  :", round(float(correct), 4))
```

```text
broken, validation, per epoch: [0.4308, 0.6082, 0.6929]
correct value after epoch 3  : 0.8934
```

Keras calls `reset_state` at the start of each epoch and of each evaluation. Without it, the counts of epoch 1 stay in the variables, and the value of epoch 3 is the recall over all three evaluations, which includes the weak model of epoch 1. The result is a number that looks plausible and is wrong. A custom metric needs a test against a reference, as the chapter does.

## 3. [judge]

**Position:** do not write a `train_step`. Use the built-in loss with `label_smoothing`.

**What a good answer weighs.** The chapter's rule is to use the smallest hook that does the job. Label smoothing is a change of the loss. The class `CategoricalCrossentropy` has the argument `label_smoothing`, and the chapter shows that a hand-written smoothed loss equals it. A custom `train_step` adds code that must be right in the forward pass, the gradient, the update and the metrics. The chapter shows four such details in one block. It also ties the project to one back end, and the team said that it is TensorFlow-only today.

**Strongest objection.** The sparse loss class does not have `label_smoothing`, so the team must convert the labels to one-hot first, or write the loss class of the chapter. This is a small cost compared with a custom step.

**What would overturn it.** A requirement that the smoothing must depend on something that a loss function cannot see, such as the epoch number. A callback that changes a variable in the loss would cover even that case, so the bar for a `train_step` is high.
