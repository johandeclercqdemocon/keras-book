## 1. [measure]

```python
import keras
import numpy as np
from keras import layers
from examples.digits import load

x_train, x_test, y_train, y_test = load()
keras.utils.set_random_seed(0)
model = keras.Sequential([keras.Input((64,)), layers.Dense(64, activation="relu"), layers.Dense(10)])
model.compile("adam", keras.losses.SparseCategoricalCrossentropy(from_logits=True), metrics=["accuracy"])
model.fit(x_train, y_train, epochs=20, batch_size=32, verbose=0)

predicted = model.predict(x_test, verbose=0).argmax(axis=1)
print("class 4 predicted as 9:", int(((y_test == 4) & (predicted == 9)).sum()))
print("class 9 predicted as 4:", int(((y_test == 9) & (predicted == 4)).sum()))
print("all errors:", int((predicted != y_test).sum()), "of", len(y_test))
```

```text
class 4 predicted as 9: 0
class 9 predicted as 4: 0
all errors: 13 of 450
```

The model makes 13 errors in 450 images. None of them is a 4 read as a 9 or a 9 read as a 4. The errors are in other pairs. A single accuracy number hides this, and a confusion matrix shows it.

## 2. [break]

```python
import keras
from keras import layers
from examples.digits import load

x_train, x_test, y_train, y_test = load()
keras.utils.set_random_seed(0)
model = keras.Sequential([keras.Input((64,)), layers.Dense(64, activation="relu"), layers.Dense(10)])
model.compile(
    "adam",
    keras.losses.SparseCategoricalCrossentropy(from_logits=False),
    metrics=["accuracy", keras.metrics.SparseTopKCategoricalAccuracy(k=3, name="top3")],
)
h = model.fit(x_train, y_train, epochs=20, batch_size=32,
              validation_data=(x_test, y_test), verbose=0).history
print("top-1:", round(h["val_accuracy"][-1], 4), " top-3:", round(h["val_top3"][-1], 4))
```

```text
top-1: 0.5711  top-3: 0.8822
```

The top-1 accuracy is 0.5711, and the top-3 accuracy is 0.8822. The right class is in the first three for 88% of the images and first for 57%. The model has learned something, but less than the correct pairing of the chapter, which reaches 0.9711 at top-1.

This is the same number as the fourth row of the table in the chapter, 0.5711, and the extra metric did not change it. The chapter also records that an earlier run without the determinism setting gave 0.7089. A broken setup like this one is unstable, so do not quote one number from it.

Top-3 accuracy does not show the fault. A model with a bad top-1 and a fair top-3 is a reason to check that the loss and the output match.

## 3. [judge]

**Position:** do not ship on the last column. Choose by the whole curve and by a stated bound.

**What a good answer weighs.** The table of the chapter has a spread of 0.011 in the last column, which is 5 images of 450. The first epoch is where the optimizers differ by a wide margin, and that matters if the budget for training is small. The right question is what the team can afford: if training runs for 10 epochs, momentum SGD reaches the plateau first. If it runs for hundreds, the choice is almost free. Run each candidate with several seeds, and compare the spread within a candidate to the difference between candidates.

**Strongest objection.** The team has one test set and one budget. A study with several seeds costs time that the project does not have. This is true, and it is a reason to pick the default that is cheapest to tune, not a reason to read a 5-image gap as a result.

**What would overturn it.** A repeated run in which one optimizer wins by more than the spread over seeds on a held-out set.
