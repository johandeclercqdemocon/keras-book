## 1. [measure]

```python
import keras
import numpy as np
from keras import layers

keras.utils.set_random_seed(0)
heads, key_dim, width = 4, 16, 64
by_hand = 3 * (width * heads * key_dim + heads * key_dim) + (heads * key_dim * width + width)

layer = layers.MultiHeadAttention(num_heads=heads, key_dim=key_dim)
x = np.zeros((1, 5, width), dtype="float32")
layer(x, x)
print("by hand:", by_hand, " count_params:", layer.count_params())
```

```text
by hand: 16640  count_params: 16640
```

Three projections for the query, the key and the value each have a kernel of `64 × 4 × 16` and a bias of `4 × 16`. The output projection has a kernel of `4 × 16 × 64` and a bias of 64.

## 2. [break]

```python
import keras
import numpy as np
from keras import layers, ops

keras.utils.set_random_seed(0)

class TransformerBlock(layers.Layer):
    def __init__(self, width, heads, hidden, **kwargs):
        super().__init__(**kwargs)
        self.attention = layers.MultiHeadAttention(num_heads=heads, key_dim=width // heads)
        self.norm_1 = layers.LayerNormalization()
        self.feed_forward = keras.Sequential([layers.Dense(hidden, activation="relu"), layers.Dense(width)])
        self.norm_2 = layers.LayerNormalization()

    def call(self, x):
        x = self.norm_1(x + self.attention(x, x))
        return self.norm_2(x + self.feed_forward(x))

class AddPositions(layers.Layer):
    def __init__(self, length, width, **kwargs):
        super().__init__(**kwargs)
        self.table = layers.Embedding(length, width)

    def call(self, x):
        return x + self.table(ops.arange(ops.shape(x)[1]))

def build(with_positions):
    keras.utils.set_random_seed(0)
    tokens = keras.Input((16,), dtype="int32")
    x = layers.Embedding(10, 32)(tokens)
    if with_positions:
        x = AddPositions(16, 32)(x)
    x = TransformerBlock(32, 2, 64)(x)
    return keras.Model(tokens, layers.GlobalAveragePooling1D()(x))

rng = np.random.default_rng(0)
batch = rng.integers(0, 10, size=(8, 16)).astype("int32")
shuffled = np.stack([row[rng.permutation(16)] for row in batch])
for with_positions in (False, True):
    model = build(with_positions)
    difference = np.abs(ops.convert_to_numpy(model(batch)) - ops.convert_to_numpy(model(shuffled))).max()
    print(f"positions={with_positions!s:5s} largest difference after shuffling: {float(difference):.6f}")
```

```text
positions=False largest difference after shuffling: 0.000000
positions=True  largest difference after shuffling: 0.172792
```

Without positions the model computes a function of the set of tokens, so the order of the tokens cannot change the output. This is the reason that it stayed at chance on the order task. With positions, the order is part of the input and the outputs differ.

## 3. [judge]

**Position:** do not choose by the `T²` alone. Measure memory and time at 4,000 tokens, and consider a model that does not read all pairs.

**What a good answer weighs.** The chapter shows that the table of scores has `T × T` entries, so 4,000 tokens give 16 million entries for each head and each example. That is a real memory cost. A GRU reads one step at a time and has a cost that grows with `T`, but it also carries its memory through 4,000 steps, and the chapter shows that a long dependency is the case where attention is exact and a window is not. Logs often have structure: most of the signal is in a few lines. A cheap model that finds those lines first can cut `T` before attention.

**Strongest objection.** On the hardware of the team, a library kernel for attention can avoid the full table. This book did not measure that, and the objection is fair.

**What would overturn it.** A measurement on the team's data and hardware of memory and accuracy for both models at the real length.
