import pathlib
import re

text = pathlib.Path("chapters/16-field-guide.md").read_text(encoding="utf-8")
table = text.split("## From symptom to cause")[1].split("The next block checks the table")[0]
rows = [line for line in table.splitlines() if line.startswith("| ") and "---" not in line]
print("rows including the header:", len(rows), " symptom rows:", len(rows) - 1)
```

rows including the header: 17  symptom rows: 16
```

The header row is not a symptom, so the table has one row fewer than the lines that start with a bar.

## 2. [break]

```python
import pathlib
import re

root = pathlib.Path(".")
text = pathlib.Path("chapters/16-field-guide.md").read_text(encoding="utf-8")
broken = text.replace("(07-callbacks-and-training-control.md)", "(07-callbacks-and-training-control-v2.md)", 1)
links = re.findall(r"\[(\d+)\]\((\d\d-[a-z0-9-]+\.md)\)", broken)
missing = sorted({name for _, name in links if not (root / "chapters" / name).exists()})
print("missing chapter files:", missing)
```

```text
missing chapter files: ['07-callbacks-and-training-control-v2.md']
```

The check finds the one link that no longer points at a file. A check that passes on a correct table and fails on this one is a check that can be trusted to notice a rename.

## 3. [judge]

**Position:** a good answer names a symptom, a cause that one run can measure, and a number with a bound.

**What a good answer weighs.** The rows of the chapter's table share a shape: a plain description of what is seen, a cause, and a figure that comes from a run. A row without a figure is a story. Take a symptom from a real project, such as "the loaded model predicts differently on the server". Ask which single change of the setup moves it. The answer is a block of ten lines that prints two numbers that must be equal and are not.

**Strongest objection.** A table of symptoms cannot cover a field. This is true. The table is a way to organize measurements, and its value comes from the measurements and not from its size.

**What would overturn it.** A symptom that no single measurement can isolate, which needs a different method, such as a trace of the whole system.
