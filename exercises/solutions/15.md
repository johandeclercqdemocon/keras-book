## 1. [measure]

```python
import os
import subprocess
import sys

env = {**os.environ, "TF_DETERMINISTIC_OPS": "1"}
losses = []
for _ in range(3):
    result = subprocess.run([sys.executable, "-m", "examples.determinism_probe"],
                            capture_output=True, text=True, env=env)
    losses.append(float(result.stdout.strip().splitlines()[-1].split()[1]))
print("runs:", len(losses), " largest difference below 1e-6:", max(losses) - min(losses) < 1e-6)
```

```text
runs: 3  largest difference below 1e-6: True
```

The losses agree to far better than 1e-6. The chapter's own measurement shows that the weights of two runs can still differ in their last bits, so the check is on the loss and with a tolerance.

## 2. [break]

```python
import os

os.environ["TF_DETERMINISTIC_OPS"] = "1"

import keras
import numpy as np

x = np.ones((16, 3), dtype="float32")
y = np.ones((16, 1), dtype="float32")

def train():
    model = keras.Sequential([keras.Input((3,)), keras.layers.Dense(1)])
    model.compile("sgd", "mse")
    model.fit(x, y, epochs=1, batch_size=4, verbose=0)

try:
    train()
    print("without a seed: no error")
except RuntimeError as error:
    print("without a seed:", str(error)[:40])

keras.utils.set_random_seed(0)
train()
print("with a seed: no error")
```

```text
without a seed: Random ops require a seed to be set when
with a seed: no error
```

With determinism on, a random operation without a seed is an error. Here the shuffle of the data in `fit` is the random operation. The line that fails is `fit`, and the message does not name the shuffle.

**What a good answer weighs.** The chapter measured a change of the loss under mixed precision and no speed, because the machine had no GPU. A 1.8-times gain on one model and one GPU is a fact about that pair. It can be smaller for a small model, which spends its time in the input pipeline and not in the layers. The chapter also shows that the optimizer is wrapped in a loss-scaling optimizer, which is an extra moving part. Loss, accuracy and the variation over seeds must be compared at the same budget.

**Strongest objection.** On modern GPUs mixed precision is the default for a reason, and the loss differences are usually small. This is likely true, and the only evidence that counts here is the team's own.

**What would overturn it.** A run on the project's model and data with several seeds, in which the accuracy difference is smaller than the spread over seeds and the speed gain is at least as large as the colleague reports.
