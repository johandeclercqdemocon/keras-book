## 1. [measure]

```python
import io
import os
import tempfile
import zipfile

import h5py
import keras
import numpy as np
from keras import layers

keras.utils.set_random_seed(0)
model = keras.Sequential([keras.Input((8,)), layers.Dense(6, activation="relu"),
                          layers.Dense(5, activation="relu"), layers.Dense(2)])
model.compile("adam", "mse")
model.fit(np.zeros((8, 8), dtype="float32"), np.zeros((8, 2), dtype="float32"), verbose=0)
path = os.path.join(tempfile.mkdtemp(), "m.keras")
model.save(path)

weights = h5py.File(io.BytesIO(zipfile.ZipFile(path).read("model.weights.h5")))
print("weight arrays:", len(model.weights), " optimizer arrays:", len(weights["optimizer"]["vars"]))
```

```text
weight arrays: 6  optimizer arrays: 14
```

Adam keeps the step count and the learning rate, and two moving averages for each weight array. For 6 arrays that is 2 + 12 = 14. This is why an Adam checkpoint is three times larger than the weights alone.

## 2. [break]

```python
import os
import tempfile

import keras
import numpy as np
from keras import layers, ops

x = np.random.default_rng(0).normal(size=(3, 5)).astype("float32")

def build(relu_after):
    keras.utils.set_random_seed(0)
    first = layers.Dense(4, activation="relu" if relu_after == 1 else None)
    second = layers.Dense(4, activation="relu" if relu_after == 2 else None)
    return keras.Sequential([keras.Input((5,)), first, second])

source, target = build(1), build(2)
path = os.path.join(tempfile.mkdtemp(), "m.weights.h5")
source.save_weights(path)
target.load_weights(path)
print("loaded without an error")
print("predictions equal:", bool(np.allclose(ops.convert_to_numpy(source(x)), ops.convert_to_numpy(target(x)))))
```

```text
loaded without an error
predictions equal: False
```

The weights file holds arrays, and the arrays fit by shape. Keras checks the shapes and not the function. A model with the same shapes and a different activation loads without a message and computes something else. Save the whole model, with its configuration, when you can.

## 3. [judge]

**Position:** give both, and say what each is for. The `.keras` file is for people who continue the work. The SavedModel is for the service.

**What a good answer weighs.** The chapter shows that the `.keras` file holds the configuration, the weights and the optimizer state, and that it needs Keras and every custom class to load. The exported model holds the computation and the weights, runs without Keras, and returned the same numbers as `predict`. It does not hold the optimizer, so it cannot continue training. The serving team usually needs the second. The research team needs the first.

**Strongest objection.** Two artifacts can drift apart. Make the export a step of the same script that saves the `.keras` file, and name both with the same version.

**What would overturn it.** A serving platform that loads Keras files directly and has your custom classes, which removes the reason for the export.
