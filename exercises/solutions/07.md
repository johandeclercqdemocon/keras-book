## 1. [measure]

```python
import keras
import numpy as np
from keras import layers
from examples.digits import load

x_train, x_test, y_train, y_test = load()
rows = np.random.default_rng(0).choice(len(x_train), 200, replace=False)
x_small, y_small = x_train[rows], y_train[rows]
loss = keras.losses.SparseCategoricalCrossentropy(from_logits=True)

for patience in (1, 5, 15):
    keras.utils.set_random_seed(0)
    model = keras.Sequential([keras.Input((64,)), layers.Dense(256, activation="relu"),
                              layers.Dense(256, activation="relu"), layers.Dense(10)])
    model.compile("adam", loss, metrics=["accuracy"])
    stopper = keras.callbacks.EarlyStopping(monitor="val_loss", patience=patience, restore_best_weights=True)
    h = model.fit(x_small, y_small, epochs=100, batch_size=32,
                  validation_data=(x_test, y_test), callbacks=[stopper], verbose=0).history
    stop, best = len(h["val_loss"]), int(np.argmin(h["val_loss"])) + 1
    print(f"patience {patience:2d}: stops at epoch {stop}, best epoch {best}, difference {stop - best}")
```

```text
patience  1: stops at epoch 29, best epoch 28, difference 1
patience  5: stops at epoch 36, best epoch 31, difference 5
patience 15: stops at epoch 46, best epoch 31, difference 15
```

The run stops `patience` epochs after the best epoch. A small patience can stop at a local minimum of a noisy curve. A large patience wastes epochs. Look at the curve of a first run to choose the value.

## 2. [break]

```python
import keras
import numpy as np
from keras import layers
from examples.digits import load

x_train, x_test, y_train, y_test = load()
rows = np.random.default_rng(0).choice(len(x_train), 200, replace=False)
x_small, y_small = x_train[rows], y_train[rows]
loss = keras.losses.SparseCategoricalCrossentropy(from_logits=True)

for mode in ("max", "min"):
    keras.utils.set_random_seed(0)
    model = keras.Sequential([keras.Input((64,)), layers.Dense(256, activation="relu"),
                              layers.Dense(256, activation="relu"), layers.Dense(10)])
    model.compile("adam", loss, metrics=["accuracy"])
    stopper = keras.callbacks.EarlyStopping(monitor="val_accuracy", mode=mode, patience=5,
                                            restore_best_weights=True)
    h = model.fit(x_small, y_small, epochs=100, batch_size=32,
                  validation_data=(x_test, y_test), callbacks=[stopper], verbose=0).history
    accuracy = model.evaluate(x_test, y_test, verbose=0)[1]
    print(f"mode={mode}: stops at epoch {len(h['val_accuracy'])}, accuracy of the returned model {accuracy:.4f}")
```

```text
mode=max: stops at epoch 17, accuracy of the returned model 0.9378
mode=min: stops at epoch 6, accuracy of the returned model 0.6444
```

With `mode="min"` the callback treats a lower accuracy as better. It stops the run at epoch 6 and returns a model with an accuracy of 0.6444, against 0.9378 for the intended setting. The code is valid and the run finishes without a message. `mode` is a direction, and a wrong value gives a worse model with no warning.

## 3. [judge]

**Position:** no. Report the accuracy on a third set that did not take part in any selection.

**What a good answer weighs.** The saved model is the best of 60 candidates, and "best" was judged on the validation set. The maximum of 60 noisy numbers is higher than the mean of the same numbers, even if every candidate is equal. The validation accuracy of the saved model is therefore an optimistic estimate. The size of the bias depends on the number of candidates and on the noise of one evaluation. With 450 validation images, one image is 0.0022, so 60 comparisons can add several images of bias.

**Strongest objection.** The bias may be small compared with other uncertainties, and a third set costs data that the team does not have. If data are scarce, cross-validation gives a less biased estimate at the cost of compute.

**What would overturn it.** A comparison, on a data set that is large enough, of the selection score and the score on a held-out third set. If the two agree within the noise, the bias is small for this setup.
