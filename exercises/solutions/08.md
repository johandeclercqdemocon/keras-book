## 1. [measure]

```python
import keras
import numpy as np
from keras import layers
from examples.digits import load

x_train, x_test, y_train, y_test = load()
rows = np.random.default_rng(0).choice(len(x_train), 200, replace=False)
x_small, y_small = x_train[rows], y_train[rows]
loss = keras.losses.SparseCategoricalCrossentropy(from_logits=True)

def test_accuracy(seed, dropout):
    keras.utils.set_random_seed(seed)
    stack = [keras.Input((64,))]
    for _ in range(2):
        stack.append(layers.Dense(256, activation="relu"))
        if dropout:
            stack.append(layers.Dropout(dropout))
    stack.append(layers.Dense(10))
    model = keras.Sequential(stack)
    model.compile("adam", loss, metrics=["accuracy"])
    model.fit(x_small, y_small, epochs=60, batch_size=32, verbose=0)
    return model.evaluate(x_test, y_test, verbose=0)[1]

for name, dropout in (("baseline", 0.0), ("dropout 0.5", 0.5)):
    scores = [test_accuracy(seed, dropout) for seed in (1, 2, 3)]
    print(f"{name:12s}", [round(s, 3) for s in scores], "spread", round(max(scores) - min(scores), 3))
```

```text
baseline     [0.933, 0.929, 0.933] spread 0.004
dropout 0.5  [0.927, 0.924, 0.929] spread 0.004
```

The spread inside a setting is 0.004, which is 2 images. The difference between the two settings is about 0.005. In the chapter, at seed 0, dropout 0.5 was 0.007 above the baseline. At seeds 1, 2 and 3 it is 0.004 to 0.006 below. The sign of the difference changes with the seed, so one seed cannot rank the two. A claim that is smaller than the spread is not a result.

## 2. [break]

```python
import keras
import numpy as np
from keras import layers
from examples.digits import load

x_train, x_test, y_train, y_test = load()
keras.utils.set_random_seed(0)
model = keras.Sequential([keras.Input((64,)), layers.Dense(256, activation="relu"),
                          layers.Dropout(0.5), layers.Dense(10)])
batch = x_test[:100]
train_a = model(batch, training=True).numpy()
train_b = model(batch, training=True).numpy()
infer_a = model(batch, training=False).numpy()
infer_b = model(batch, training=False).numpy()
print("two training=True calls equal :", bool(np.array_equal(train_a, train_b)))
print("two training=False calls equal:", bool(np.array_equal(infer_a, infer_b)))
print("training vs inference equal   :", bool(np.array_equal(train_a, infer_a)))
```

```text
two training=True calls equal : False
two training=False calls equal: True
training vs inference equal   : False
```

With `training=True`, dropout draws a new mask in each call, so the outputs differ from call to call. With `training=False` the layer does nothing, and the calls are equal. If a service calls the model with `training=True` by mistake, the same request gives different answers, and each answer is the output of a smaller random network. The mistake is easy to make in a custom loop and hard to see in a single request.

## 3. [judge]

**Position:** the manager is right for this model, and wrong as a general rule.

**What a good answer weighs.** The curve is flat from 800 to 1,347 images at 0.973 for this model on this task. More images of the same kind will not move it. The curve does not say that no data would help. A different model, with more capacity, can use more data, and new data of a kind that the test set lacks can show new errors. The curve is one model on one test set.

**Strongest objection.** A flat curve of two points is thin evidence. Each point comes from one subset and one seed. A curve with several subsets for each size would tell more.

**What would overturn it.** Repeat each size with five subsets. If the mean at 1,347 is still within the spread of the mean at 800, stop. If it is not, continue.
