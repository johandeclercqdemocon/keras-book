# Exercises — Chapter 3

Chapter: [Layers and weights](../chapters/03-layers-and-weights.md) · module: [`examples/ch03_layers_and_weights.py`](../examples/ch03_layers_and_weights.py) · solutions: [03](solutions/03.md)

**1. [measure]** A model has `Dense(10)` on an input of 20 features, then `BatchNormalization`, then `Dense(1)`. Use the layer attributes to count the trainable and the non-trainable parameters. Expected: 241 trainable parameters and 20 non-trainable parameters.

**2. [break]** Write a layer whose `build` method creates its weight with `trainable=False`, put it in a model with a `Dense(1)` and train with SGD. Show that the layer weight does not change. Then change one argument so that the weight does change. Expected: `False` and then `True`.

**3. [judge]** A colleague wants a custom layer that keeps a running maximum of its input in a non-trainable weight, to use at inference. Is this a good use of the mechanism of this chapter? What does a good answer weigh?
