# Exercises — Chapter 2

Chapter: [Tensors and ops](../chapters/02-tensors-and-ops.md) · module: [`examples/ch02_tensors_and_ops.py`](../examples/ch02_tensors_and_ops.py) · solutions: [02](solutions/02.md)

**1. [measure]** Cast the integer 2049 to `float16` and back to a NumPy value. Report the number you get. Then find the smallest positive integer that `float16` cannot represent exactly. Expected: 2048 for the first part, and 2049 for the second.

**2. [break]** Write a function `noisy(x)` that returns `x + keras.random.normal(x.shape, seed=3)`. Call it twice on the same input and show that the noise is identical. Then change one line so that two calls give different noise and the whole run is still repeatable. Expected: `True` before the change, `False` after.

**3. [judge]** The team runs on TensorFlow only, and has done so for four years. A reviewer asks you to write a new custom layer with `tf.*` functions because "they are better documented and we will never switch". What does a good answer weigh?
