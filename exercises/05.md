Chapter: [Data pipelines](../chapters/05-data-pipelines.md) · module: [`examples/ch05_data_pipelines.py`](../examples/ch05_data_pipelines.py) · solutions: [05](solutions/05.md)

**1. [measure]** Count the batches in one epoch of the `PyDataset` of the chapter for batch sizes 32, 64 and 100. Report the size of the last batch for each. Expected: 43, 22 and 14 batches, with last batches of 3, 3 and 47 images.

**2. [break]** Adapt a `Normalization` layer on the training images, then apply it to the test images in which you have set pixel 24 to zero. Show that the huge output disappears. Then explain why that fix would hide a real problem if you used it in production.

**3. [judge]** A colleague reports 99% validation accuracy on a new data set. The code uses `validation_split=0.2` on arrays that a database query produced. What does a good answer ask and weigh before anyone celebrates?
