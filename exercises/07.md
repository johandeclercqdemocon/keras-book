# Exercises — Chapter 7

Chapter: [Callbacks and training control](../chapters/07-callbacks-and-training-control.md) · module: [`examples/ch07_callbacks_and_training_control.py`](../examples/ch07_callbacks_and_training_control.py) · solutions: [07](solutions/07.md)

**1. [measure]** Run the early-stopping setup of the chapter with `patience` 1, 5 and 15. For each value report the epoch where the run stops and the best epoch. Expected: the run stops exactly `patience` epochs after the best epoch, whenever the run stops before epoch 100.

**2. [break]** Give `EarlyStopping` the arguments `monitor="val_accuracy"` and `mode="min"`, so that a lower accuracy counts as an improvement. Report the epoch where the run stops, and the test accuracy of the returned model, for `mode="min"` and for `mode="max"`. Say which result is the intended one. Expected: the two runs stop at different epochs, and the `"min"` run returns a worse model.

**3. [judge]** `ModelCheckpoint` with `save_best_only=True` monitors the validation set, and so does `EarlyStopping`. After 60 epochs of selection, can you report the validation accuracy of the saved model as the accuracy of the model? What does a good answer weigh?
