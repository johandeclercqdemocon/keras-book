[Chapter 11](11-sequences.md) ended with a limit: a convolution has a reach, and a recurrent layer must carry its memory one step at a time. Attention removes both limits. Every position can read every other position in one step.

This chapter builds attention from its formula, then uses the Keras layer, then builds a transformer block. The order task of Chapter 11 is the test. It has a known answer, and it needs order.

## Attention by hand

For each query, attention computes a score against every key. It divides the scores by the square root of the key width, applies a softmax, and uses the result as weights on the values. In symbols, the output is `softmax(Q Kᵀ / √d) V`.

The next block writes this with NumPy and compares it with `keras.ops.dot_product_attention`. The input has the layout `(batch, time, heads, width)`.

```python
import numpy as np
from keras import ops

rng = np.random.default_rng(2)
q = rng.normal(size=(1, 5, 2, 8)).astype("float32")

built_in = ops.convert_to_numpy(ops.dot_product_attention(q, q, q))

scores = np.einsum("bthd,bshd->bhts", q, q) / np.sqrt(q.shape[-1])
weights = np.exp(scores - scores.max(-1, keepdims=True))
weights /= weights.sum(-1, keepdims=True)
by_hand = np.einsum("bhts,bshd->bthd", weights, q)

print("weights shape (batch, heads, query, key):", weights.shape)
print("each row of weights sums to 1:", bool(np.allclose(weights.sum(-1), 1.0)))
print("by hand equals keras.ops below 1e-5:", bool(np.abs(by_hand - built_in).max() < 1e-5))
```

```text
weights shape (batch, heads, query, key): (1, 2, 5, 5)
each row of weights sums to 1: True
by hand equals keras.ops below 1e-5: True
```

The weight array has one row for each query and one column for each key. Each row sums to 1, so the output is a weighted average of the values. The hand-written version and the built-in version agree.

## The Keras layer

`keras.layers.MultiHeadAttention` adds learned projections for the query, the key and the value, runs several attention heads, and projects the result back. With `return_attention_scores=True` it also returns the weights.

The next block checks three properties of the layer: the shape of the weights, equivariance under a permutation of the input, and the effect of a causal mask.

```python
import keras
import numpy as np
from keras import layers, ops

keras.utils.set_random_seed(0)

attention = layers.MultiHeadAttention(num_heads=2, key_dim=8)
x = np.random.default_rng(1).normal(size=(1, 6, 16)).astype("float32")

output, scores = attention(x, x, return_attention_scores=True)
print("output shape:", tuple(output.shape), " weights shape:", tuple(scores.shape))
print("rows sum to 1:", bool(np.allclose(ops.convert_to_numpy(scores).sum(-1), 1.0, atol=1e-5)))

order = np.array([3, 0, 5, 1, 4, 2])
permuted = ops.convert_to_numpy(attention(x[:, order], x[:, order]))
original = ops.convert_to_numpy(attention(x, x))
print("permuted input gives permuted output:", bool(np.abs(permuted - original[:, order]).max() < 1e-5))

changed = x.copy()
changed[:, 4] += 1.0
open_before = ops.convert_to_numpy(attention(x, x))
open_after = ops.convert_to_numpy(attention(changed, changed))
causal_before = ops.convert_to_numpy(attention(x, x, use_causal_mask=True))
causal_after = ops.convert_to_numpy(attention(changed, changed, use_causal_mask=True))
print("change token 4, outputs at positions 0-3:")
print("  without mask moved by", round(float(np.abs(open_after[:, :4] - open_before[:, :4]).max()), 3))
print("  with causal mask moved by", float(np.abs(causal_after[:, :4] - causal_before[:, :4]).max()))
```

```text
output shape: (1, 6, 16)  weights shape: (1, 2, 6, 6)
rows sum to 1: True
permuted input gives permuted output: True
change token 4, outputs at positions 0-3:
  without mask moved by 0.513
  with causal mask moved by 0.0
```

The weights have the shape `(batch, heads, query, key)`: 2 heads and a 6 × 6 table. A permutation of the input gives the same permutation of the output. This is the important fact: **attention has no sense of order.** A sequence and its shuffled copy give the same set of outputs.

The causal mask limits each position to the positions before it and itself. With the mask, a change at token 4 does not move the outputs at positions 0 to 3. Without the mask it moves them. A model that predicts the next token needs the mask. A model that classifies a whole sequence does not.

## A transformer block

A transformer block has two parts, each with a residual connection and a layer normalization. The first part is attention. The second is a small dense network that is applied to each position alone. The block below is a `keras.layers.Layer` with these parts.

```python
import keras
from keras import layers

keras.utils.set_random_seed(0)

class TransformerBlock(layers.Layer):
    def __init__(self, width, heads, hidden, **kwargs):
        super().__init__(**kwargs)
        self.attention = layers.MultiHeadAttention(num_heads=heads, key_dim=width // heads)
        self.norm_1 = layers.LayerNormalization()
        self.feed_forward = keras.Sequential([layers.Dense(hidden, activation="relu"), layers.Dense(width)])
        self.norm_2 = layers.LayerNormalization()

    def call(self, x):
        x = self.norm_1(x + self.attention(x, x))
        return self.norm_2(x + self.feed_forward(x))
```

The residual connection `x + attention(x, x)` lets the gradient pass around the attention. The layer normalization keeps the scale of each position stable.

#### `keras.layers.LayerNormalization`

```text
keras.layers.LayerNormalization(
    axis=-1,
    epsilon=0.001,
    center=True,
    scale=True,
    beta_initializer='zeros',
    gamma_initializer='ones',
    beta_regularizer=None,
    gamma_regularizer=None,
    beta_constraint=None,
    gamma_constraint=None,
    **kwargs,
)
```

The layer subtracts the mean of each sample and divides by its standard deviation over the feature axis. It has no moving statistics, so training and inference compute the same thing.

## The test: order

The next block trains the same transformer three times on the order task of Chapter 11. The first model has no position information. The second adds a position embedding that is called outside a layer, in the way that many examples write it. The third adds the position embedding inside a layer, so that Keras tracks its weights.

```python
import keras
import numpy as np
from keras import layers, ops

rng = np.random.default_rng(0)

def make(n, length=16, vocabulary=10):
    x = rng.integers(3, vocabulary, size=(n, length))
    positions = np.array([rng.permutation(length)[:2] for _ in range(n)])
    x[np.arange(n), positions[:, 0]] = 1
    x[np.arange(n), positions[:, 1]] = 2
    return x.astype("int32"), (positions[:, 0] < positions[:, 1]).astype("int32")

x_train, y_train = make(6000)
x_test, y_test = make(2000)

class TransformerBlock(layers.Layer):
    def __init__(self, width, heads, hidden, **kwargs):
        super().__init__(**kwargs)
        self.attention = layers.MultiHeadAttention(num_heads=heads, key_dim=width // heads)
        self.norm_1 = layers.LayerNormalization()
        self.feed_forward = keras.Sequential([layers.Dense(hidden, activation="relu"), layers.Dense(width)])
        self.norm_2 = layers.LayerNormalization()

    def call(self, x):
        x = self.norm_1(x + self.attention(x, x))
        return self.norm_2(x + self.feed_forward(x))

class AddPositions(layers.Layer):
    def __init__(self, length, width, **kwargs):
        super().__init__(**kwargs)
        self.table = layers.Embedding(length, width)

    def call(self, x):
        return x + self.table(ops.arange(ops.shape(x)[1]))

def build(positions, width=32):
    keras.utils.set_random_seed(0)
    tokens = keras.Input((16,), dtype="int32")
    x = layers.Embedding(10, width)(tokens)
    if positions == "outside a layer":
        x = x + layers.Embedding(16, width)(ops.arange(16))
    elif positions == "inside a layer":
        x = AddPositions(16, width)(x)
    x = TransformerBlock(width, heads=2, hidden=64)(x)
    x = layers.GlobalAveragePooling1D()(x)
    model = keras.Model(tokens, layers.Dense(1)(x))
    model.compile("adam", keras.losses.BinaryCrossentropy(from_logits=True),
                  metrics=[keras.metrics.BinaryAccuracy(threshold=0.0, name="acc")])
    return model

print(f"{'positions':16s} {'weights':>8s} {'train acc':>10s} {'test acc':>9s}")
for positions in ("none", "outside a layer", "inside a layer"):
    model = build(positions)
    h = model.fit(x_train, y_train, epochs=30, batch_size=64,
                  validation_data=(x_test, y_test), verbose=0).history
    print(f"{positions:16s} {model.count_params():8d} {h['acc'][-1]:10.3f} {h['val_acc'][-1]:9.3f}")
```

```text
positions         weights  train acc  test acc
none                 8897      0.510     0.502
outside a layer      8897      1.000     1.000
inside a layer       9409      1.000     1.000
```

Without positions the model scores 0.502, which is chance, and its training accuracy is also near chance. Both models with positions score 1.000.

The weights column shows a fault. The model with the embedding outside a layer has 8,897 weights, the same as the model with no positions. Keras did not register the embedding, because it was called on a plain tensor and not on a symbolic input. The 512 weights are a fixed random table that no gradient reaches. The model still scores 1.000, because any fixed and distinct code for each position carries order.

The model with `AddPositions` has 9,409 weights. The 512 extra weights are 16 × 32, one vector of 32 numbers for each of the 16 positions, and they are trained. A model that depends on a trained table must have the table inside a layer. Check `count_params()` after you add a component. The number tells you whether Keras sees it.

The task is the one on which the bag-of-tokens model scored 0.502 in Chapter 11. A transformer without positions is, for this purpose, a bag of tokens with a more complex mixing step.

## What to take from this chapter

1. Attention is a weighted average of the values, with weights from a softmax. It is exact to write by hand.
2. It has no sense of order. Add a position signal, or the model sees a set.
3. A causal mask is a separate choice. Use it when each position must not see the future.
4. The block is a layer. Stack it, and the cost of each block is its attention weights and its feed-forward weights.

## How it works

`MultiHeadAttention` has four groups of weights. The query, the key and the value each have a projection that maps the input of width `d` to `heads × key_dim` numbers. The output projection maps the heads back to width `d`. The attention step itself, `softmax(Q Kᵀ / √d) V`, has no weights.

This explains the weight count and the behavior of the layer. The next block lists the weights of one layer and counts them by hand.

```python
import keras
import numpy as np
from keras import layers

keras.utils.set_random_seed(0)

layer = layers.MultiHeadAttention(num_heads=2, key_dim=8)
layer(np.zeros((1, 6, 16), dtype="float32"), np.zeros((1, 6, 16), dtype="float32"))
for weight in layer.weights:
    print(f"{weight.path:30s} {tuple(weight.shape)}")

d, heads, key = 16, 2, 8
by_hand = 3 * (d * heads * key + heads * key) + (heads * key * d + d)
print("by hand:", by_hand, " layer:", layer.count_params())
layer(np.zeros((1, 10, 16), dtype="float32"), np.zeros((1, 10, 16), dtype="float32"))
print("after a call with 10 tokens instead of 6:", layer.count_params())
```

```text
multi_head_attention/query/kernel (16, 2, 8)
multi_head_attention/query/bias (2, 8)
multi_head_attention/key/kernel (16, 2, 8)
multi_head_attention/key/bias  (2, 8)
multi_head_attention/value/kernel (16, 2, 8)
multi_head_attention/value/bias (2, 8)
multi_head_attention/attention_output/kernel (2, 8, 16)
multi_head_attention/attention_output/bias (16,)
by hand: 1088  layer: 1088
after a call with 10 tokens instead of 6: 1088
```

The count matches. The number of weights does not change when the length of the sequence changes from 6 to 10. The invariant is this: the layer is the same function at every position, and only the table of scores `Q Kᵀ` grows with the length. That table has `T × T` entries for a sequence of `T` tokens. The cost of attention grows with the square of the length, and the cost of a convolution or a recurrent layer grows with the length.

### Parameters

##### `keras.ops.dot_product_attention`

| parameter | default | what it does | what goes wrong |
|---|---|---|---|
| `query` | required | the queries | a 3-D input raises `ValueError: dot_product_attention only supports 4D inputs` |
| `key` | required | the keys | — |
| `value` | required | the values | — |
| `bias` | `None` | a number added to each score | — (a bias of -1e9 on key 0 gave the same output as a mask on key 0) |
| `mask` | `None` | a boolean array. `False` removes a key | — |
| `scale` | `None` | the factor of the scores. With `None`, `1 / sqrt(width)` | with 1.0 in place of 1/√8, the mean largest weight of a row rose from 0.659 to 0.896: the weights are sharper |
| `is_causal` | `False` | remove the keys after each query | — (a change at position 4 did not move the outputs at 0 to 3) |
| `flash_attention` | `None` | use a fused kernel when it can | `True` raises `ValueError: Flash attention is not supported in tensorflow backend` |
| `attn_logits_soft_cap` | `None` | limit the scores with `tanh` | any value raises `ValueError: attn_logits_soft_cap is only supported for JAX on TPU` |

##### `keras.layers.MultiHeadAttention`

| parameter | default | what it does | what goes wrong |
|---|---|---|---|
| `num_heads` | required | the number of heads | — |
