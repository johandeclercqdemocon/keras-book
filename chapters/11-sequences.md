Text, sensor traces and call logs are sequences. A model for them must answer one question first: does the order of the tokens carry information? If it does not, a bag of tokens is enough. If it does, the model needs a part that reads order.

This chapter builds a task in which only order matters, so that each model type gets a clean score. The data are made by the code. Nothing is downloaded.

## From text to numbers

A model reads integers. The `TextVectorization` layer turns strings into integers. You call `adapt` on a list of strings to build the vocabulary, and then the layer maps every word to its position in the vocabulary.

```python
from keras import layers

vectorizer = layers.TextVectorization(max_tokens=20, output_sequence_length=6)
vectorizer.adapt(["the cat sat", "the dog sat on the mat", "a cat"])

print("vocabulary:", [str(word) for word in vectorizer.get_vocabulary()])
print("'the cat sat on a sofa' ->", vectorizer(["the cat sat on a sofa"]).numpy()[0].tolist())
print("'a cat' ->", vectorizer(["a cat"]).numpy()[0].tolist())
```

```text
vocabulary: ['', '[UNK]', 'the', 'sat', 'cat', 'on', 'mat', 'dog', 'a']
'the cat sat on a sofa' -> [2, 4, 3, 5, 8, 1]
'a cat' -> [8, 4, 0, 0, 0, 0]
```

Id 0 is the padding value, and id 1 is the unknown word. The word `sofa` is not in the vocabulary, so it becomes 1. The layer sorts the vocabulary by frequency, so `the` has id 2. The output has a fixed length of 6: the short sentence is padded with zeros at the end.

An `Embedding` layer then turns each id into a vector of learned numbers. An embedding with a vocabulary of 10 and a width of 16 is a table of 10 × 16 = 160 weights.

```python
import keras
import numpy as np
from keras import layers

keras.utils.set_random_seed(0)

embedding = layers.Embedding(input_dim=10, output_dim=16)
tokens = np.array([[3, 1, 4, 1, 5]])
vectors = embedding(tokens)
print("input shape :", tokens.shape)
print("output shape:", tuple(vectors.shape))
print("weights     :", embedding.count_params())
print("same id, same vector:", bool(np.array_equal(vectors.numpy()[0, 1], vectors.numpy()[0, 3])))
```

```text
input shape : (1, 5)
output shape: (1, 5, 16)
weights     : 160
same id, same vector: True
```

The output has one more axis than the input: the width of the embedding. The same id always gives the same vector. The embedding does not know the position of a token. Position has to come from a layer that reads the sequence.

## A task in which only order matters

Each sequence has 16 tokens from a vocabulary of 10. Token 1 appears once and token 2 appears once. The other tokens are random from 3 to 9. The label is 1 if token 1 comes before token 2.

A model that ignores order cannot do better than chance. The two tokens appear in every sequence, so any count of tokens is the same for both labels.

```python
import keras
import numpy as np
from keras import layers

rng = np.random.default_rng(0)

def make(n, length=16, vocabulary=10):
    x = rng.integers(3, vocabulary, size=(n, length))
    positions = np.array([rng.permutation(length)[:2] for _ in range(n)])
    x[np.arange(n), positions[:, 0]] = 1
    x[np.arange(n), positions[:, 1]] = 2
    return x.astype("int32"), (positions[:, 0] < positions[:, 1]).astype("int32"), positions

x_train, y_train, _ = make(6000)
x_test, y_test, test_positions = make(2000)
print("share of label 1 in the test set:", round(float(y_test.mean()), 3))

def build(kind):
    keras.utils.set_random_seed(0)
    stack = [keras.Input((16,), dtype="int32"), layers.Embedding(10, 16)]
    if kind == "bag":
        stack += [layers.GlobalAveragePooling1D(), layers.Dense(32, activation="relu")]
    elif kind == "flatten":
        stack += [layers.Flatten(), layers.Dense(64, activation="relu")]
    elif kind == "conv":
        stack += [layers.Conv1D(32, 3, activation="relu"), layers.GlobalMaxPooling1D(),
                  layers.Dense(32, activation="relu")]
    elif kind == "simple rnn":
        stack += [layers.SimpleRNN(32)]
    elif kind == "gru":
        stack += [layers.GRU(32)]
    elif kind == "lstm":
        stack += [layers.LSTM(32)]
    stack.append(layers.Dense(1))
    model = keras.Sequential(stack)
    model.compile("adam", keras.losses.BinaryCrossentropy(from_logits=True),
                  metrics=[keras.metrics.BinaryAccuracy(threshold=0.0, name="acc")])
    return model

models = {}
print(f"{'model':11s} {'weights':>8s} {'train acc':>10s} {'test acc':>9s}")
for kind in ("bag", "flatten", "conv", "simple rnn", "gru", "lstm"):
    models[kind] = build(kind)
    history = models[kind].fit(x_train, y_train, epochs=15, batch_size=64,
                               validation_data=(x_test, y_test), verbose=0).history
    print(f"{kind:11s} {models[kind].count_params():8d} {history['acc'][-1]:10.3f} {history['val_acc'][-1]:9.3f}")
```

```text
share of label 1 in the test set: 0.501
model        weights  train acc  test acc
bag              737      0.514     0.502
flatten        16673      1.000     1.000
conv            2817      0.826     0.805
simple rnn      1761      1.000     1.000
gru             4993      1.000     1.000
lstm            6465      1.000     1.000
```

The bag model scores 0.502 on the test set, which is chance. Its training accuracy is also near chance. It cannot represent the answer. The `flatten` model scores 1.000, because the length is fixed and it gives each position its own weights. The three recurrent models also score 1.000.

The `conv` model is in between at 0.805. This is the interesting case. It sees windows of 3 tokens. A filter of width 3 has a reach of 3 tokens, and it has no memory of earlier windows. The next block tests this.

## The reach of a filter

The next block measures the claim. It splits the test set by the distance between token 1 and token 2 in the sequence. It then scores the `conv` model on each part, and the `gru` model for comparison.

The block trains the two models again, in the same way as before, so that it runs on its own.

```python
import keras
import numpy as np
from keras import layers

rng = np.random.default_rng(0)

def make(n, length=16, vocabulary=10):
    x = rng.integers(3, vocabulary, size=(n, length))
    positions = np.array([rng.permutation(length)[:2] for _ in range(n)])
    x[np.arange(n), positions[:, 0]] = 1
    x[np.arange(n), positions[:, 1]] = 2
    return x.astype("int32"), (positions[:, 0] < positions[:, 1]).astype("int32"), positions

x_train, y_train, _ = make(6000)
x_test, y_test, positions = make(2000)
distance = np.abs(positions[:, 0] - positions[:, 1])

def train(kind):
    keras.utils.set_random_seed(0)
    stack = [keras.Input((16,), dtype="int32"), layers.Embedding(10, 16)]
    if kind == "conv":
        stack += [layers.Conv1D(32, 3, activation="relu"), layers.GlobalMaxPooling1D(),
                  layers.Dense(32, activation="relu")]
    else:
        stack += [layers.GRU(32)]
    model = keras.Sequential(stack + [layers.Dense(1)])
    model.compile("adam", keras.losses.BinaryCrossentropy(from_logits=True))
    model.fit(x_train, y_train, epochs=15, batch_size=64, verbose=0)
    return (model.predict(x_test, verbose=0)[:, 0] > 0).astype("int32")

predictions = {kind: train(kind) for kind in ("conv", "gru")}
print(f"{'distance':>9s} {'pairs':>6s} {'conv':>7s} {'gru':>7s}")
for low, high in [(1, 2), (3, 4), (5, 8), (9, 15)]:
    chosen = (distance >= low) & (distance <= high)
    scores = [float((predictions[k][chosen] == y_test[chosen]).mean()) for k in ("conv", "gru")]
    print(f"{low:3d} to {high:2d} {int(chosen.sum()):6d} {scores[0]:7.3f} {scores[1]:7.3f}")
```

```text
 distance  pairs    conv     gru
  1 to  2    511   1.000   1.000
  3 to  4    402   0.652   1.000
  5 to  8    649   0.710   1.000
  9 to 15    438   0.858   1.000
```

Two tokens at a distance of 1 or 2 always fit in one window of 3. The `conv` model is right for all of these pairs: its accuracy is 1.000. For every larger distance it is far from right, between 0.652 and 0.858. The `gru` model is right at every distance: 1.000.

The accuracy of the `conv` model does not fall steadily with the distance. It is 0.858 for the longest distances, which is higher than at distance 3 or 4. This was not what the text predicted before the measurement.

The block does not show the reason.

One candidate is that a token at the edge of the sequence appears in fewer windows. That gives the model a weak cue of position. [Exercise 2](../exercises/11.md) tests that candidate. Pairs with a token at the edge score 1.000. Pairs that lie inside score 0.504, which is chance.

The firm result is the first one. A filter has a reach, and a pair inside the reach is easy. A recurrent layer, or an attention layer ([Chapter 12](12-attention-and-transformers.md)), has no such limit. A convolution needs depth to reach as far.

## Padding and masks

Real sequences have different lengths. The usual fix is to pad the short ones with zeros to a common length. Then the padding is part of the input, and a recurrent layer reads it like any token.

The `mask_zero=True` argument of `Embedding` creates a mask. Later layers use the mask and skip the padded steps. The next block gives the same sequence to a GRU, with and without padding. It compares the two outputs.

```python
import keras
import numpy as np
from keras import layers, ops

plain = np.array([[3, 4, 5]])
padded = np.array([[3, 4, 5, 0, 0]])

for mask_zero in (False, True):
    keras.utils.set_random_seed(0)
    model = keras.Sequential([
        keras.Input((None,), dtype="int32"),
        layers.Embedding(10, 8, mask_zero=mask_zero),
        layers.GRU(4),
    ])
    difference = np.abs(ops.convert_to_numpy(model(plain)) - ops.convert_to_numpy(model(padded))).max()
    print(f"mask_zero={mask_zero!s:5s} difference between plain and padded: {float(difference):.4f}")
```

```text
mask_zero=False difference between plain and padded: 0.0458
mask_zero=True  difference between plain and padded: 0.0000
```

Without a mask, the two padding zeros change the output by 0.0458. With a mask, the output is exactly equal. The difference is small here, but it is not zero. A model that you train with padding and serve without padding, or the reverse, gives different answers when no mask is in use.

## How it works

An `Embedding` layer is a table of vectors with one row for each id. It does not compute anything. Given an id, it returns that row. This is the same result as a one-hot vector times the table, and the lookup is faster because it skips the zeros.

The next block shows both ways, and it shows that the layer has no way to know the position of a token.

```python
import keras
import numpy as np
from keras import layers

keras.utils.set_random_seed(0)

embedding = layers.Embedding(10, 4)
tokens = np.array([[3, 1, 4, 1]])
embedding(tokens)
table = embedding.get_weights()[0]

lookup = table[tokens]
one_hot = np.eye(10)[tokens] @ table
print("table shape:", table.shape, " weights:", embedding.count_params())
print("lookup equals one-hot times table:", bool(np.allclose(lookup, one_hot, atol=1e-6)))
print("same id at two positions gives the same row:", bool(np.array_equal(lookup[0, 1], lookup[0, 3])))
```

```text
table shape: (10, 4)  weights: 40
lookup equals one-hot times table: True
same id at two positions gives the same row: True
```

The result confirms the two statements.

The invariant is this: the output at a position is a function of the id and nothing else. Any order information must come from a layer after the embedding. A recurrent layer gets it from the order of its steps. A convolution gets it from the offsets in its window. Attention gets it from a position vector that you add ([Chapter 12](12-attention-and-transformers.md)).
